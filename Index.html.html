Raum beitreten

Die Verbindung läuft über öffentliche MQTT-Server (kein eigener Server nötig, funktioniert auch hinter Firewalls). Für den Einladungs-Link muss diese Datei im Web liegen. Der Raum-Code funktioniert immer, auch wenn jeder die Datei lokal öffnet. Räume sind nicht privat geschützt – teile den Code nur mit Freunden.
